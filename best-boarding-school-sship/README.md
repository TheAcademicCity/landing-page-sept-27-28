# best-boarding-school-sship

WhatsApp / Gallabox landing page with **Early Bird Enrolment Benefit** (scholarship) messaging.

- **URL:** `/best-boarding-school-sship/`
- **Edit:** `index.html` in this folder (not root `index.html`).
- **Shared assets:** `../css/`, `../js/`, `../images/`
- **Scholarship-specific:** `../css/early-bird.css`, `../js/early-bird-countdown.js`
- **Thank-you:** `thank-you.html` (same as main WhatsApp LP)

Countdown ends **30 November 2026** (IST); benefit blocks hide after **1 Dec 2026 00:00 IST**.

To refresh from the main WhatsApp LP (without scholarship blocks), run `scripts/sync-landing-variant.ps1 -VariantSlug best-boarding-school-sship` and re-apply scholarship sections.
